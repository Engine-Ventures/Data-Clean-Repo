Which New Deals folders show up in the record?

One row per company folder under New Deals / 02. Companies — the closest thing EV has to a list of every company it has opened a file on. Each is looked for in the two records this repo is built from: the whole deal meeting deck, all 153 meetings of it, and the Affinity export. N in both columns is the half worth reading — material in storage for a company that never reached a slide and has no CRM record. Both joins are on name, because the index carries no domain and no entity id, so every Y carries the name it matched and how.

P1 enrichment worklist

The advanced-stage and discussed companies with gaps. Solid means the value is known; dashed means nobody has looked yet; struck through means someone looked and it genuinely is not available.

Generated from data/pipeline.db by scripts/build_ui.py. Opened as a file this is a read-only snapshot; served by scripts/serve.py it also offers Add company — with an optional public lookup that suggests a website and country for you to accept or correct — and tag editing on any company. Both write through the validated path in src/evpipeline/validate.py. Editing enrichment values, merging and gap resolution stay command-line only. Coverage is shown next to every count because a bare count off this dataset is not yet quotable.
